# Project PolyCog
<sub>Copyright (c) 2025 Sylv. All Rights Reserved.</sub>

A behavioral sandbox composed of blocks.

The state of this codebase at the moment is in prototype. That is, expect bugs to occur.

## License
Project PolyCog is licensed as All Rights Reserved and will likely never be Open Source. Different licenses are being
considered, but at present, this is not planned.

## Price
Project PolyCog has no plans of publishing to game platforms. This is because it requires the latest Vulkan features that most computers do not support, let alone mobile devices and consoles. This game will never be ported to console.

## Compiling
You are free to compile and execute Project PolyCog provided that you do not distribute the source code or binary
executables.
